# Commercial Release IP & Licensing Policy

This project is intended for commercial distribution through Google Play and other app stores.

## Rules

1. Project code must be original or used under a license that explicitly permits commercial distribution.
2. Do not copy source code, UI assets, icons, images, text, datasets, or documentation from third parties unless the project has documented permission or a compatible license.
3. Review every new dependency before adoption and record its license and intended use.
4. Do not introduce GPL/AGPL or other copyleft dependencies without an explicit project-level legal review and approval.
5. Preserve required copyright notices, attribution, NOTICE files, and license texts for permitted third-party dependencies.
6. Do not ship third-party trademarks, logos, screenshots, or marketing assets without permission.
7. Keep API keys, private credentials, signing secrets, and personal data out of source control and release artifacts.
8. Before each store release, perform an IP/license/dependency audit and verify release configuration.
9. AI-generated content and user-generated content must follow applicable store policies and include appropriate reporting/moderation controls where required.

## Practical interpretation

"Original" means authored for this project or otherwise legally licensed for the intended commercial use. A public GitHub repository is not automatically free to copy or redistribute.

This document is a project engineering rule, not legal advice. For disputed ownership or licensing questions, obtain professional legal review before release.
