# Store Release Checklist

This project is intended for commercial distribution on Google Play and other Android stores.

## Intellectual property

- New source code must be original project code or use a license that permits the intended commercial distribution.
- Do not copy proprietary source code, designs, screenshots, icons, logos, articles, or other protected assets.
- Review every new dependency license before adoption.
- Preserve required copyright notices, licenses, and attribution for permitted third-party dependencies.
- Do not use third-party trademarks or logos in a way that implies affiliation without permission.
- Keep written permissions for any third-party intellectual property that is intentionally used.

## Security

- Never commit API keys, private keys, passwords, or tokens.
- Do not embed exchange secrets in the APK.
- Prefer server-side or user-provided credentials with secure storage where applicable.

## Release quality

- Debug builds must compile cleanly before release work is considered complete.
- Unit tests and critical integration tests must pass.
- The app must not crash, freeze, or expose broken screens.
- Store screenshots and descriptions must represent the real app.
- Final release must use proper signing and a release build configuration.

## Policy note

Google Play requires app and Store Listing content to be original or properly licensed and prohibits infringement of copyright, trademark, patent, and other intellectual-property rights. See the current Google Play Intellectual Property and Functionality policies before submission.
