## Non-negotiable acceptance rules
- Legacy Strategy add/import/edit/delete/export flows must remain reachable.
- Missing data must never become positive evidence.
- Growth Scanner must distinguish early signals from assets that already pumped.
- Scores must be deterministic/testable where they are algorithmic.
- Live integrations must expose unavailable/stale data states rather than fabricate values.
- Final completion requires automated verification and a successful Android package build.
